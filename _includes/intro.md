I work on machine learning for knowledge graphs, where the data keeps changing and many entities look alike. I build models that add signals which are usually left out, such as how the graph changes and time itself, so that entity linking, link prediction and recommendation stay accurate on sparse, long-tail and look-alike entities. The same problem appears in industry as entity resolution under data drift.
